#快速开始

开箱流程

  1. 上电，等待 3 秒初始化完成（屏幕显示主界面）
  2. 长按 OK 进入设置菜单
  3. 按 UP/DOWN 选 水渠，进入后设置 渠道类型、水槽编号
  4. 进入 测量参数，根据传感器规格设置 窗口宽度、滤波次数 等
  5. 长按 SHIFT 进入 历史查询，确认传感器数据
  6. 主屏 短按 UP/DOWN 切换瓦片页查看详情 / 趋势 / 累计

首次使用提醒

  • 渠道类型/水槽编号改变后，水位上下限会被自动覆盖为新槽型默认值
  • 4-20mA 校准值范围 0~7999，超出有效范围的值可能导致电流输出不准确
  • 出厂默认 4mA 校准值 1006，20mA 校准值 3811，一般无需重新校准

#按键操作

按键主屏 (详情/趋势/累计)设置菜单 (3 级)编辑参数
OK 长按 = 进入设置 (启用密码时先验证) 进入下一级 / 保存并返回上级 保存当前值
UP 短按 = 切换到上一瓦片页 选择上一项 增加当前值 (按当前步进)
DOWN 短按 = 切换到下一瓦片页 选择下一项 减少当前值 (按当前步进)
SHIFT 长按 = 进入历史查询 返回上一级 短按 = 切换步进 (1/10/100/...)，长按 = 取消编辑

步进切换 (SHIFT 短按)

进入编辑页后短按 SHIFT，步进在 1 → 10 → 100 → 1000 → 10000 之间循环。 当前步进位会高亮显示，方便快速定位要修改的位数。 累计流量编辑器支持更宽的步进范围。

                            ├─ 高级设置      (8 项)

15 秒无操作自动返回主屏。在设置菜单任一层级停留超过 15 秒将自动退出，避免意外耗电或挡操作。

显示名范围默认值说明

#报警参数

四路继电器对应的报警阈值与回差。瞬时流量与各阈值实时比较，超出触发吸合。

显示名继电器范围默认值说明
上限报警 (Alarm High) 继电器 1 0 ~ 99999 19.44 m³/h 流量 ≥ AH 触发吸合；流量 < AH - DH 恢复释放。
下限报警 (Alarm Low) 继电器 2 0 ~ 99999 0.0 m³/h 流量 ≤ AL 触发吸合；流量 > AL + DL 恢复释放。
上上限报警 (Alarm HH) 继电器 3 ≥ AH 100.0 m³/h 流量 ≥ AAH 触发吸合；流量 < AAH - DH 恢复释放。回差与 AH 共用 DH。
下下限报警 (Alarm LL) 继电器 4 ≤ AL 0.0 m³/h 流量 ≤ AAL 触发吸合；流量 > AAL + DL 恢复释放。回差与 AL 共用 DL。
上限回差 (Alarm High DB) — 0 ~ 99999 2.0 m³/h AH 与 AAH 共用的回差。流量必须低于 (阈值 - DH) 才解除。
下限回差 (Alarm Low DB) — 0 ~ 99999 2.0 m³/h AL 与 AAL 共用的回差。流量必须高于 (阈值 + DL) 才解除。

关联校验

设置 AAH 时不能小于 AH；设置 AAL 时不能大于 AL。 违反时系统会提示参数冲突。

采样延迟 (Sample Rate) 0 ~ 1000 ms 50 ms 传感器两次采样之间的间隔。值越大功耗越低，但响应越慢。
盲区 (Blind Area) 0 ~ 1000 mm 50 mm 传感器正下方的测量盲区。距离 < 盲区 时数据无效。
加权平均 (Wgt Average) 0 ~ 10 8 传感器加权平均系数 W。

#计算逻辑

设备通过传感器测量水位，再根据所选堰槽公式计算瞬时流量：

水位范围计算结果
低于水位下限瞬时流量 = 0
在水位上下限之间按堰槽公式正常计算
高于水位上限按上限值计算（提示溢出）

水位上下限来源： 首次切换渠道类型/水槽编号时，设备自动填入当前槽型的默认水位范围。用户可在设置菜单中独立修改。再次切换槽型会覆盖用户修改。

侧收缩修正

当 渠宽 B > 0 且 B > b 时按收缩堰处理：

b_e = b - 0.2 × H
若 b_e < 0 → b_e = 0
  • B = 0 → 全宽堰，b_e = b
  • B > 0 且 B ≤ b → 不收缩，b_e = b
  • B > b → 按上式修正 b_e
示例：全宽堰 vs 收缩堰 (1.0m 堰宽, H=0.3m) 
全宽堰 (B = 0):
  b_e = 1.0
  Q = 1838.0 × 1.0 × 0.301^1.5 = 303.5 L/s

收缩堰 (B = 2.0m):
  b_e = 1.0 - 0.2 × 0.30 = 0.94
  Q = 1838.0 × 0.94 × 0.301^1.5 = 285.3 L/s

#常见问题

Q: 主屏一直显示 "L:error" ？

传感器离线。检查：

  1. 传感器电源/线缆是否松动
  2. 传感器地址是否与本机配置一致
  3. 传感器波特率/停止位是否与本机一致
  4. 查看设备日志中是否有传感器离线记录

Q: 修改了 4-20mA 量程后电流没变化？

检查当前瞬时流量是否在 4mA 和 20mA 量程范围内。若瞬时流量 < 4mA 量程则电流钳位到 4mA；若 > 20mA 量程则钳位到 20mA。

Q: 累计流量断电后丢了一部分？

设备每 2 秒自动保存累计数据，断电后最大丢失 2 秒数据。如果备用电池耗尽，可能丢失更多数据，建议定期更换电池。

Q: 修改渠道类型后水量上下限变了？

这是正常行为。渠道类型 / 水槽编号变更时会自动覆盖水位上下限为新槽型默认值，如需自定义请在切换后重新调整。

Q: 20mA 量程无法设置到很大？

20mA 量程上限被限制为"当前槽型理论最大流量 × 1.2 倍裕量"。这是为了保证输出电流有合理的分辨率。如需更大的量程，请更换支持更大流量的水槽规格。

Q: 继电器不动作？

  1. 检查传感器是否离线 (离线时所有报警清除)
  2. 检查报警阈值设置 (AAH ≥ AH, AAL ≤ AL)
  3. 检查主屏 显示报警 选项是否关闭 (仅影响 UI 指示，不影响继电器)
