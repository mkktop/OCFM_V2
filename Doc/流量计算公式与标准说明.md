## 1. 计算基础

| 项目 | 说明 |
|------|------|
| **水位测量** | 超声波/雷达传感器测距，水位 `H = 安装高度 − 距离`（单位 m） |
| **流量基准单位** | 内部计算统一使用 **L/s**，显示按 `instant_unit` 配置转换 |
| **累计流量** | 使用 `double` 精度累加（防精度丢失），单位 m³ |
| **重力加速度** | `g = 9.80665 m/s²`（标准重力） |
| **堰型选择** | `canals_type`（1=巴歇尔槽 / 2=三角堰 / 3=矩形堰），`channel_id` 选具体规格 |
| **水位钳位** | `H > water_level_up` → 按 `water_level_up` 计算；`H < water_level_down` → 流量归零 |

## 2. 巴歇尔槽（Parshall Flume）

### 2.1 公式

```
Q = K · H^n    （Q 单位 L/s，H 单位 m）
```

- 巴歇尔槽为**短喉道量水槽**，**不使用水头修正 Kh**（区别于薄壁堰）
- 仅适用于**自由流**条件（下游淹没度低于临界值，通常 `H₂/H₁ < 0.6~0.7`）

### 2.2 标准出处

| 标准 | 说明 |
|------|------|
| **CJ/T 3008.3-1993** | 《城市排水流量堰槽测量标准 巴歇尔量水槽》（本项目系数来源） |
| ISO 9826:1991 | 《明渠水流测量——巴歇尔水槽和孙奈利水槽》（CJ/T 参照） |
| ASTM D1941 | 美国材料试验协会巴歇尔槽标准 |

> 测量精度：2%~5%（依据 CJ/T 3008.3-1993）

## 3. 三角堰（V 型薄壁堰）

### 3.1 公式（Kindsvater-Shen 方法）

```
Q = K · (H + Kh)^2.5    （Q 单位 L/s，H 单位 m）
```

其中：

```
K = Ce · (8/15) · √(2g) · tan(θ/2) · 1000
he = H + Kh    （有效水头）
```

| 符号 | 含义 |
|------|------|
| `Ce` | 有效流量系数（含黏性与表面张力修正） |
| `Kh` | 有效水头修正长度（补偿表面张力与黏性效应），单位 m |
| `θ` | 堰口顶角（度） |
| `he` | 有效水头 = 实测水头 H + Kh |

### 3.2 Ce 系数（经验拟合公式）

```
Ce = 0.607165052 − 0.000874467·θ + 6.103933e-6·θ²
```

> 来源：Ackers / Harrison 对 Kindsvater-Shen 实验数据的曲线拟合（θ 单位为度）。

### 3.3 Kh 系数

```
Kh(ft) = 0.01449 − 0.0003396·θ + 3.298e-6·θ² − 1.062e-8·θ³
Kh(m)  = Kh(ft) × 0.3048
```

> **⚠️ 关键**：公式输出单位为**英尺(ft)**，填入代码前必须 `× 0.3048` 转米。
> 90° 时 `Kh = 0.00085 m`（即 ISO 1438-1 规定的标准值 **0.85 mm**）。

### 3.4 标准出处

| 标准 | 说明 |
|------|------|
| **CJ/T 3008.1-1993** | 《城市排水流量堰槽测量标准 三角形薄壁堰》 |
| **ISO 1438:2017** | 《Hydrometry — Open channel flow measurement using thin-plate weirs》（薄壁堰明渠流量测量） |
| Kindsvater & Shen (1960) | V 型堰流量系数与水头修正的奠基性论文 |

> 测量精度：依据 ISO 1438，标准安装条件下可达 1%~2%。

## 4. 矩形堰（矩形薄壁堰）

### 4.1 公式（Francis + 侧收缩修正）

```
Q = K · b_eff · (H + Kh)^1.5    （Q 单位 L/s，H 单位 m）
```

其中：

```
K    = Cd · (2/3) · √(2g) · 1000
b_eff = 有效堰宽（含侧收缩修正）
he    = H + Kh    （有效水头）
```

### 4.2 系数取值

| 系数 | 值 | 出处 |
|------|-----|------|
| `Cd` | 0.622（Francis），代码反算 0.6225 | Francis 公式 |
| `Kh` | 0.001 m | Kindsvater-Carter 方法 |
| `K` | 1838.0（由 Cd 反算） | — |

### 4.3 侧收缩修正（Francis 公式）

当渠道宽度 `B > 堰宽 b`（即收缩堰，b < B）时，水流在堰板两侧发生侧收缩，有效过流宽度减小：

```
b_eff = b − 0.2·H    （Francis 两侧收缩，每侧减 0.1H）
```

当 `B ≤ b` 或 `B = 0`（全宽堰/未配置渠宽）时：

```
b_eff = b    （无侧收缩）
```

> 配置参数：`channel_width`（渠宽 B，mm）、`weir_height`（堰高 p，mm），通过 Modbus 寄存器 0x0109/0x010A 设置。
>
> 适用条件：Francis 全收缩公式要求堰板距渠壁距离 `(B−b)/2 ≥ 4H`。当不满足时为近似值。

|------|------|
| **CJ/T 3008.2-1993** | 《城市排水流量堰槽测量标准 矩形薄壁堰》 |
| **ISO 1438:2017** | 薄壁堰明渠流量测量 |
| Francis (1850s) | 矩形堰经典经验公式 |

> 测量精度：1%~4%（依据 CJ/T 3008.2-1993）。

## 5. HJ 15-2019 合规验证

### 5.1 流量测量误差检测（§6.3.2）

检测方法：在最大水位高度的 20%、50%、80% 三个点分别记录流量示值，与理论值对比，误差限值 **≤2%**。

检测堰型：
- **90° 三角堰**（p/B 取 0.2）
- **矩形缺口薄壁堰**（堰宽 0.5m，渠宽 1.0m，p 取 0.25m）
- **4 号巴歇尔槽**（喉宽 0.152m）

### 5.2 90° 三角堰 Kh 修正前后对比

修正前 Kh=0.00301m（错误）→ 修正后 Kh=0.00085m（ISO 1438 标准）：

| 检测点 | 水位 H(m) | 修正前 Q(L/s) | 修正后 Q(L/s) | 修正前误差 | 修正后误差 | 判定 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 20% | 0.080 | 2.710 | 2.537 | +6.81% | ~0% | ❌→✅ |
| 50% | 0.200 | 25.347 | 24.678 | +2.71% | ~0% | ❌→✅ |
| 80% | 0.320 | 80.942 | 79.595 | +1.69% | ~0% | ✅→✅ |

> 修正前在 20%/50% 检测点误差超 2%，**会导致型式检测不合格**；修正后全部检测点误差趋近于 0。

### 5.3 巴歇尔槽与矩形堰

- **4 号巴歇尔槽**：K/n 值与 CJ/T 3008.3-1993 标准完全一致，无需修正。
- **矩形堰**：Cd=0.622、Kh=0.001m、侧收缩 0.2H 均符合 Francis/ISO 1438，无需修正。
